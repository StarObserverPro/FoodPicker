# FoodPicker · 扎心版今天吃什么

手机优先的“今天吃什么”决策器。首页可以直接随机选一道菜，也可以回答八道题，根据当下偏好得到推荐和人格插画。核心流程不需要运行时依赖或 API key。

## Current experience

- 首次进入先播放约 16 秒的苏醒式动态文字：句子逐段浮现，“饿晕了”大字停顿，“吃什么”逐字弹出并放大，“了吗？”作为同一句的小字落在右下方，接着淡出露出原有文选首页；可随时跳过，系统减少动态效果时直接进入首页。本地时间决定饭点台词。

- 八题流程：五道随机抽取的人格题、一道校准题、两道当下状态题。问题和判词保持娱乐化，不冒充心理诊断。
- 推荐权重约为：真实偏好为主、当日/时辰玄学做扰动、最后用判词把决定讲圆。
- 问答结果显示人格插画、判词和菜名；随机结果显示一张完整插画及三个备选。两个入口均支持换菜、返回首页、生成分享图、保存图片和复制链接。
- 默认菜单面向中国可获得性：保留完整中国菜单，并纳入国内常见汉堡、炸鸡、披萨、意面、三明治、塔可等国际快餐/大众西餐。
- 旧国际完整菜单仍保留在 `food-data.js`；`?menu=world` 或 `?menu=international` 可切到世界池做内部 review。
- `personality-engine.js` 为菜单生成推荐标签，并对少数代表菜做精确覆盖；`psychic-app.js` 负责交互和分享。
- 网页使用同分辨率 WebP，原始 PNG 保留；人格图在结果页直接显示图层，分享时才合成。图片失败仍可选菜并生成文字分享卡。
- 保留 iPhone safe-area、PWA manifest 与离线缓存。

## Structure

```text
index.html              扎心版入口、问答与结果页结构
styles.css              视觉系统、问答/结果/分享与响应式样式
wake-intro.js           苏醒开场的时序、饭点文案和跳过逻辑
wake-intro.css          动态排版、文字重音和淡出转场
food-data.js            完整旧菜单库、原语名称与搜索索引
food-policy.js          中国默认池 / 国际扩展池切分策略
personality-engine.js   人格、推荐评分与抽样
persona-art.js          人格插画描述、图层加载与分享合成
psychic-app.js          八题交互、结果与分享任务
manifest.webmanifest    PWA manifest
sw.js                   Service Worker
functions/              旧版图片/分享 Functions，暂保留兼容资产
assets/                 插画、原始 PNG、WebP 与 PWA 图标
scripts/optimize-art.py 开发用图片编码工具（Pillow）
tests/                  入口、推荐、资源、分享及缓存回归
```

## Local preview

用 Node.js 启动本地 HTTP 预览：

```text
node local-server.mjs
```

然后访问 `http://127.0.0.1:4173`。部署环境下可同时使用 PWA 与系统分享能力。

部署细节见 [`README_DEPLOY.md`](./README_DEPLOY.md)。

## 文案维护

当前问答的实际显示文案在 `psychic-app.js`（包括对引擎题目的覆盖及额外题库）；16 类人格的 48 条结果判词在 `persona-art.js`。首页、加载提示与分享操作文字也属于审读范围。`personality-engine.js` 中未显示的题目提示、旧版推荐解释，以及保留兼容的旧入口，不代表当前页面口吻。

2026-10-27 文案复审：问答采用自然的当代中文口语，保留少量日常语气；判词通过人物动作和短场景保留叙述感，减少武断的人格判断、说教结尾、刻意耍贫和不成立的动态词搭配。清淡选项明确写为“可以花点心思，只想吃得清爽些”，与原有 `light/fresh` 权重一致。文学摘录保留原文与署名，本轮未做引文出处核验。推荐权重、角色映射和菜单范围不变。前端与离线缓存版本更新为 v21，现有问答与判词保留本轮复审结果。

本轮验证：13 项现有回归测试及修改脚本的语法检查通过。375×667、390×844、430×932 的真实浏览器排版检查尚未完成：执行环境缺少 Chromium，浏览器下载失败；需在预览环境补看问答长选项、结果判词与分享图。

## 苏醒开场（2026-10-27）

在 `index.html` 的 `.paper` 内叠放 `#wakeIntro`；其下是原有的文选首页及两个入口按钮，动画结束或点“跳过”后立即恢复交互。开场不新增图片、依赖或网络请求；词组及时间点在 `wake-intro.js` 中，字体与字效在 `wake-intro.css` 中。问句为“你想好吃什么了吗？”，其中“了吗？”右下角小字与“吃什么”同步出现，不另设字幕拍子。`?intro=0` 可直接跳过以便测试；系统要求减少动态效果时自动跳过。回归检查包括 375×667、390×844、430×932 的本地 Chromium 隔离渲染、重音文字位置、跳过/完整退场和减动效；正式站点及微信内置浏览器仍需上线后检查。
